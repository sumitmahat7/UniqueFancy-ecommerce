# Unique Fancy - Online Clothing Store

## Project Overview
E-commerce web application for clothing store built using Java EE, JSP, Servlets, and MySQL.

## Technologies Used
- Java EE
- JSP & Servlets
- MySQL Database
- HTML/CSS
- Apache Tomcat

## How to Run
1. Import database from `database/schema.sql`
2. Configure Tomcat server
3. Run `mvn clean package cargo:run`
4. Access at `http://localhost:8080/UniqueFancy`
